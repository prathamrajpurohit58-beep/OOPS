## 💡 What is OOP?

Object-Oriented Programming (OOP) is a programming paradigm based on the concept of **objects** and **classes**.
It helps in writing reusable, secure, and maintainable code by organizing programs into real-world entities.

## 🎯 Advantages of OOP

* Reusability of code
* Better data security
* Easy maintenance
* Modular programming
* Improved scalability
